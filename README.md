# Vue Frontend

Welcome to the main frontend interface! This application is built using Vue 3 and Vite, providing a modern and responsive interface.

## Prerequisites

- Node version: 22.11.0
- npm version: 11
- vue: 3.5

## Getting Started

To get started with the project, clone the repository and install the dependencies:

```sh
npm install
```

Compile and Hot-Reload for Development

```sh
npm run dev
```

Type-Check, Compile and Minify for Production

```sh
npm run build
```
